How to publish your changes

  1. Download the updated content.js file above. Keep that exact filename.
  2. In your website’s GitHub repository, open the folder that contains index.html.
  3. Select Add file → Upload files, and upload the new content.js. Choose to replace the existing file and commit the change.
  4. Wait for Pages to finish deploying, then refresh the website.

The first installation requires all files in the website ZIP. After that, routine content and photo changes need only content.js. Before editing, refresh this page to load the latest published content and coordinate with colleagues to avoid overwriting each other’s work.
