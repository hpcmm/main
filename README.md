# HPC-MM website — complete recovery package

Start with DEPLOYMENT.md. This is a static website: no build, npm install, or custom Actions workflow is required.

All recovered repository files are included. content.js and all three photographs are preserved byte for byte from commit f274baf1bafe5b20a38c142a5b0c0892b3fa0eae. All member profiles, publications, editor, ORCID import and sync scripts are retained.

For routine updates, open the hosted editor.html, edit the fields, download content.js and replace it at the repository root. Photos are separate files; see IMAGE-UPLOAD-GUIDE.md. Back up content.js before editing. Publishing an older copy overwrites newer edits.

The automatic weekly ORCID workflow is not installed in this recovery package. Manual ORCID import remains available. See SETUP-AUTOMATIC-UPDATES.md for the distinction.
